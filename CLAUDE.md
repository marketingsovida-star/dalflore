# Continuidade do projeto DalFlore

Leia `docs/CONTINUIDADE-CLAUDE.md` antes de fazer alterações. Esse documento registra o estado aprovado pelo usuário, o sistema visual, decisões rejeitadas e a estrutura técnica.

Use `docs/skills/frontend-design/SKILL.md` como apoio. As decisões explícitas do usuário registradas no documento de continuidade prevalecem sobre recomendações genéricas da skill.

Continue o projeto existente; não substitua o site por um novo template. Inspecione o código e a versão publicada antes de editar. Aguarde o próximo pedido do usuário para definir a próxima alteração visual.
